# 任务描述

## 添加三个页面

1. 写一个echarts折线图，数据是中国从1949年到2025年的人口出生数和死亡人数的对比，具体数据从网上查找公开数据
2. 写一个echarts折线图，数据是中国从2025年到2100年的人口出生数和死亡人数的预测的对比，具体数据从网上查找公开数据
3. 写一个echarts折线图，数据是中国从1949年到2100年的人口变化，具体数据从网上查找公开数据

## 要求

1. 样式使用tailwindcss实现，页面可以实现自适应
2. 折线图要求是随年份动态变化的
3. 具体数据如果网上可以查找到公开数据，则使用网上的，如果查找不到，则根据变化趋势确定数据
